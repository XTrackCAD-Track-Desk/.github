## What Is XTrackCAD

XTrackCAD is a local Windows layout editor for a model railroad you already keep. It gives you a named track desk, a short turnout list, and a plan view that points back to the same railroad. It does not try to own every window on the PC. It sits beside the files you already use and holds only the layout that is open now.
The idea behind XTrackCAD own layout is small on purpose: one desk, one list, one path back. Extra plans wait for their own title. XTrackCAD starts with a local profile and does not need a complex account system.
People who keep a home layout, a club railroad they administer, or a shelf plan they already own use XTrackCAD track desk in different ways, but the job stays the same. Untitled copies leave the live set. The last handoff stays on the railroad you keep.

## Starting with XTrackCAD

Prerequisites: A PC you own, a layout you already keep, and permission to open a local helper.

1. **Prepare:** Close leftover untitled plans and open the last XTrackCAD session on a railroad you keep.
2. **Configure:** Read the track desk and the turnout list, then drop anything that belongs to a different job.
3. **Test:** Finish one visible plan view inside XTrackCAD own layout.
4. **Refine:** Write what changed, then close with a shorter turnout list than you found.
5. **Apply:** Keep XTrackCAD track desk on the same railroad during the next session.
6. **Maintain:** If the desk feels crowded, leave extra plans off the live set.
